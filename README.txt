         Offline Coop v1.9 FIX — ГОТОВАЯ К УСТАНОВКЕ ВЕРСИЯ
              для GTA V Legacy (одна копия игры, без онлайна)

В ЭТОЙ ВЕРСИИ ИСПРАВЛЕНО:
  ✅ Мерцание (strobe) при сплит-скрине
  ✅ Сломанное управление на геймпаде (приведено к нативной GTA)
  ✅ Блокировка удара/стрельбы без прицела (разрешено)
  ✅ Проваливание P2 сквозь текстуры
  ✅ P2 не удаляется движком игры
  ✅ Автовоскрешение P2 + автотелепорт при десинке
  ✅ Ошибка UnauthorizedAccessException (логи в scripts/OfflineCoop/)
  ✅ P2 получает пистолет/винтовку/нож сразу при спавне
  ✅ Приоритет процесса выше обычного (текстуры подгружаются)

ПОДГОТОВКА (нужно сделать ОДИН раз, до установки мода):
────────────────────────────────────────────────────────────
  1. Установил в папку с GTA5.exe:
       • Script Hook V           http://dev-c.com/gtav/scripthookv/
         (dinput8.dll + ScriptHookV.dll в корень игры)
       • ScriptHookVDotNet v3    https://github.com/crosire/scripthookvdotnet/releases
         (СКАЧАЙ версию "ScriptHookVDotNet.zip", НЕ "SDK" —
          закинь ScriptHookVDotNet2.dll, ScriptHookVDotNet3.dll,
          ScriptHookVDotNet.Shared.dll В КОРЕНЬ GTA V)
       • NativeUI                https://github.com/Guad/NativeUI/releases
         (NativeUI.dll В ПАПКУ scripts/)
  2. УБЕДИСЬ ЧТО У ТЕБЯ НЕ ЗАПУЩЕН GTA Online — мод только для
     СЮЖЕТНОГО РЕЖИМА (Single Player). В онлайне за это банят!
  3. Если стоит ReShade / ENB / NaturalVision Evolved / QuantV /
     любой другой графический мод — ПЕРЕИМЕНУЙ ИХ dll (dxgi.dll,
     d3d11.dll и т.п.) на время игры в кооп. Любые сторонние графические
     хуки ВСЕГДА вызывают мерцание вместе с этим модом.

УСТАНОВКА:
──────────
  1. Скопируй ВСЕ ФАЙЛЫ из этой папки в папку GTA V
     (где лежит GTA5.exe), ПОДТВЕРДИВ ЗАМЕНУ/СЛИЯНИЕ папок.
     Итоговая структура должна быть такая:
        GTA5.exe
        ├─ dinput8.dll                      (Script Hook V)
        ├─ ScriptHookV.dll                  (Script Hook V)
        ├─ ScriptHookVDotNet2.dll           (SHVDN3)
        ├─ ScriptHookVDotNet3.dll           (SHVDN3)
        ├─ OfflineCoopMod.asi               ✅ из этого архива
        ├─ xinputblock.asi                  ✅ из этого архива (нижний регистр!)
        ├─ ScriptHookVDotNet.ini            ✅ из этого архива
        └─ scripts/
            ├─ OfflineCoop.dll              ✅ из архива
            ├─ OfflineCoop.ini              ✅ НОВЫЙ фикс-конфиг
            ├─ OfflineCoopFix.cs            ✅ скрипт-фикс багов
            ├─ NativeUI.dll                 (обязательно!)
            ├─ SharpDX.dll                  ✅ из архива
            └─ SharpDX.DirectInput.dll      ✅ из архива

  2. ЗАПУСТИ ФАЙЛ:
        01_Настройка_и_чек_перед_запуском.bat
     Он попросит перетащить в окно GTA5.exe и отключит
     полноэкранную оптимизацию Windows — это ГЛАВНАЯ причина мерцания.
     Делать от имени Администратора не обязательно.

  3. Зайди в игру → Настройки → Графика и ОБЯЗАТЕЛЬНО поставь:
        • Тип экрана .......................... Оконный без рамки
        • Вертикальная синхронизация ........... ВКЛ (НЕ "Половина"!)
        • DirectX .............................. DirectX 11
        • Сглаживание MSAA .................... ВЫКЛ или x2
        • TXAA / TAA .......................... ВЫКЛ
        • NVIDIA Reflex ....................... ВЫКЛ
        • Масштаб расстояния прорисовки ....... не выше 70
        • Частота обновления .................. как у твоего монитора
        • Игнорировать предложенное ограничение памяти — ВКЛ
     Эти настройки убирают 99% мерцания.

  4. Если видеокарта NVIDIA: открой Панель управления NVIDIA →
     Управление параметрами 3D → Программные настройки → добавь GTA5.exe:
        • Вертикальный синхроимпульс .......... Вкл
        • Тройная буферизация ................. Вкл
        • Режим низкой задержки ............... Выкл
        • Предпочтительный режим питания ...... Режим макс. производительности
        • Сглаживание MFAA .................... Вкл (сгладит картинку вместо MSAA)
     На AMD: аналогично в Adrenalin включи VSync Always On, выключи Anti-Lag.

ПЕРВЫЙ ЗАПУСК:
─────────────
  1. Запусти GTA V, дождись загрузки сюжета.
  2. В левом верхнем углу увидишь уведомление ~g~OfflineCoop Fix Helper загружен~w~.
     Если оно появилось — всё работает.
  3. Нажми NumLock на клавиатуре (включи лампочку).
  4. Нажми N  — появится второй игрок.
  5. Нажми K  — экран разделится пополам (P1 слева, P2 справа).
  6. Первый игрок играет с клавиатуры и мыши как обычно.
     Второй игрок — на джойстике, подключённом ВТОРЫМ по счёту.

УПРАВЛЕНИЕ ИГРОК 2 (джойстик):
──────────────────────────────
     Левый стик    — идти / бежать (нажми A чтобы бежать быстрее)
     Правый стик   — камера
     LT (левый курок)   — прицеливание
     RT (правый курок)  — огонь / удар / газ в машине
     A             — спринт
     B             — рукопашный удар / ручной тормоз
     X             — прыжок / карабкаться
     Y             — сесть / выйти из машины
     LB            — смена оружия
     RB            — укрытие
     D-Pad         — быстрые слоты
     Start         — пауза

ДОПОЛНИТЕЛЬНЫЕ КЛАВИШИ:
───────────────────────
     F6            — принудительно телепортировать P2 к тебе
     Numpad "-"    — телепорт встроенный в оригинальный мод
     Insert        — перезагрузить скрипты (если что-то зависло)
     PageUp        — меню мода (выбор модели P2, внешний вид)
     K             — включить/выключить сплит
     N             — заспавнить / убрать второго игрока

ЕСЛИ ДЖОЙСТИК УПРАВЛЯЕТ И ПЕРВЫМ И ВТОРЫМ ИГРОКОМ:
─────────────────────────────────────────────────────
  1. Нажми Alt+Tab, вытащи джойстик из USB и вставь обратно.
  2. Если не помогло — открой scripts/OfflineCoop.ini, поменяй
     CONTROLLER_INDEX=1  на  CONTROLLER_INDEX=0, сохрани,
     вернись в игру и нажми Insert (перезагрузка скриптов).
  3. Для PS4/PS5/не Xbox-джойстиков используй DS4Windows, он
     прикидывает твой джойстик как Xbox-контроллер.

ЕСЛИ ЕСТЬ МЕРЦАНИЕ:
───────────────────
  • Убедись что стоит ОКОННЫЙ БЕЗ РАМКИ (не полный экран!).
  • Проверь что VSync стоит ВКЛ. в игре, а не "Half".
  • Отключи MSAA выше x2, выключи TXAA, выключи Reflex.
  • Отключи ReShade/ENB если они есть.
  • Закрой Chrome/Яндекс Браузер с включённым аппаратным ускорением
    (иногда они вызывают мерцание во время игры).
  • В NVIDIA Panel включи ТРОЙНУЮ БУФЕРИЗАЦИЮ.
  • Если на 144Hz мониторе мерцает — попробуй ограничить FPS в игре
    до 60 (на время игры в кооп) или через Rivatuner. Это временное
    ограничение хука, полная правка кода ASI требует Visual Studio.

ОГРАНИЧЕНИЯ (неисправимые без полной переработки ASI):
──────────────────────────────────────────────────────
  • Мод работает ТОЛЬКО в сюжетном режиме (в онлайне бан!).
  • Камера P2 — только от третьего лица (от первого нет рук P2).
  • При очень быстрой езде на гиперкарах P2 иногда выкидывает —
    просто нажми F6 чтобы телепортировать его обратно.
  • Сюжетные миссии проходи осторожно: если P2 убежит далеко от P1 —
    он будет телепортирован обратно.
